# 訂單串接 Google 試算表：設定教學

整體流程：顧客在網站結帳 → 網站把訂單送到 Google Apps Script（GAS）→ GAS 驗證並以**試算表的價格**重新計算 → 寫入試算表、寄通知信。

```
網站 index.html ──POST──▶ GAS 網頁應用程式 ──▶ Google 試算表
                                              ├─ Orders      一筆訂單一列（可改「狀態」）
                                              ├─ OrderItems  一個品項一列（利於統計）
                                              ├─ Menu        商品價格／是否供應（以此為準）
                                              └─ Config      通知信箱、暫停接單、彙整時間
```

## 一、建立試算表與腳本（約 5 分鐘）
1. 到 Google 試算表建立一份新的空白試算表，命名「金禾鍋貼訂單」。
2. 選單 **擴充功能 → Apps Script**。
3. 把 `gas/Code.gs` 全部內容貼進編輯器，覆蓋原本的 `myFunction`。
4. 左側 **專案設定（齒輪）→ 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」**，回編輯器開啟 `appsscript.json`，貼上 `gas/appsscript.json` 的內容。
5. 上方函式選 **`setup`** → 執行 → 依指示授權（會看到「Google 尚未驗證這個應用程式」，點「進階 → 前往…」即可，這是你自己的腳本）。
6. 完成後試算表會多出 `Orders / OrderItems / Menu / Config` 四個分頁。
7. 到 **Config** 分頁，把 `NOTIFY_EMAIL` 填成接收通知的信箱。

## 二、部署為網頁應用程式
1. 右上 **部署 → 新增部署作業 → 類型選「網頁應用程式」**。
2. 執行身分：**我**；誰可以存取：**所有人**。
3. 部署後複製「網頁應用程式網址」（結尾是 `/exec`）。
4. 用瀏覽器開啟該網址，看到 `{"ok":true,"service":"jinhe-orders",...}` 就代表成功。

> 之後修改 `Code.gs` 必須 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」**，網址才會套用新程式。

## 三、接上網站
在 `index.html` 找到這一行，貼上網址（或把網址交給 Claude 幫你改）：
```js
const ORDER_ENDPOINT='https://script.google.com/macros/s/xxxxxxxx/exec';
```
留空 `''` 則維持原本的「模擬結帳」。

## 四、日常使用
- **改價格／下架**：直接改 `Menu` 分頁（價格以這裡為準；網站畫面上的價格要另外同步修改）。取消勾選「供應中」，該商品就無法下單。
- **處理訂單**：在 `Orders` 的「狀態」欄用下拉選單切換（新訂單 → 製作中 → 可取餐 → 已完成／已取消），會自動記錄更新時間與顏色。
- **暫停接單**：`Config` 的 `ORDERING_OPEN` 改成 `FALSE`。
- **每日彙整信**：每天固定時間寄出訂單數、營業額、熱銷前五名。改時間後執行一次 `installTriggers`。

## 五、已內建的防護
| 風險 | 處理 |
|---|---|
| 有人改網頁傳低價 | 後端只收「商品ID＋數量」，金額由 `Menu` 重新計算 |
| 連點／網路重試造成重複訂單 | 每次結帳有唯一 requestId，重送會回傳同一筆結果；按鈕送出時停用 |
| 機器人灌單 | 隱藏欄位（honeypot）＋同一電話 30 秒內限一筆 |
| 同時下單訂單編號重複 | 使用 LockService 序列化，編號格式 `JH-20261127-001` |
| 試算表公式注入（`=…`） | 姓名、地址、備註開頭是 `= + - @` 時自動加跳脫 |
| 品項規則被繞過 | 後端重新檢查：禮盒限外帶／宅配、宅配必填地址、數量 1–99 |

## 六、上線前請注意
- 這會讓網站**真的收集姓名、電話、地址**。網站目前還有多處「模擬／概念展示／不傳送個資」的字樣（首頁標示、頁尾、FAQ「如何線上點餐」、隱私權政策、電子報），啟用前請改成符合實際的說明，並在隱私權政策載明蒐集項目、用途與保存期間。
- 目前流程是「**取餐時付款**」，沒有線上金流。
- 網頁應用程式網址是公開的（所有人可存取是必要的），安全性靠上表的後端驗證；請勿把試算表分享給不相關的人。
- 免費 Gmail 每日可寄約 100 封通知信；GAS 同時間處理量有限，單店規模足夠。
